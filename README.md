# Calculator Project

This project is a simple calculator program written in Python.

## Description
The calculator allows the user to enter two numbers and select an operation.
The supported operations are:
- Addition
- Subtraction
- Multiplication
- Division

## Programming Language
Python

## Project Files
- calculator.py : Main calculator program
- test_calculator.py : Unit test file for the calculator functions
- README.md : Project documentation file

## How to Run the Program
1. Open the terminal inside the project folder.
2. Run the following command:
   py calculator.py

## How to Run Unit Tests
1. Open the terminal inside the project folder.
2. Run the following command:
   py test_calculator.py

## Notes
- The calculator takes input from the user.
- Unit tests are written to automatically verify the correctness of the functions.
